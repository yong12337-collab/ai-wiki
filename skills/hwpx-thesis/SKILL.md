# HWPX 학위논문 채우기

학교가 준 **HWPX 서식 파일**을 바탕으로 원고를 채운다. 서식 규정(여백·글꼴·제목 체계)은 **서식 파일이 정한다**. 이 스킬은 규정을 새로 만들거나 추측하지 않는다.

## 준비물
1. 학교 공식 HWPX 서식 (예: 한국외국어대학교 대학원 학위논문 서식 — 대학원 홈페이지에서 받기)
2. 원고 Markdown (AI WIKI의 `AI원고/…/00_전체원고.md`를 그대로 써도 된다)
   - `# 제목` → 논문 제목, `## 장` → 장 제목(개요 1, 새 쪽), `### 절` → 절 제목(개요 2), 빈 줄로 문단 구분
   - `- 항목` → 목록 문단, `## 참고문헌` 아래 목록 → 참고문헌 문단

서식 파일이 없으면 만들지 말고 사용자에게 공식 서식을 요청한다. 구형 `.hwp`는 지원하지 않으므로 한글에서 HWPX로 저장해 달라고 안내한다.

## 실행
```bash
python3 scripts/fill_hwpx.py 서식.hwpx 원고.md 결과.hwpx [--toc]
```
- `--toc`: 제목 뒤에 장·절 목차 문단을 넣는다(쪽 번호는 한글에서 "차례 새로 고침"으로 갱신).
- 스크립트는 끝에 자체 검증(mimetype 첫 항목·무압축, 본문 XML 파싱, 첫 문단의 용지 설정 유지)을 하고 결과를 출력한다. 검증 실패 시 파일을 만들지 않는다.

## 동작 원리
- `Contents/header.xml`에서 스타일 이름으로 `바탕글`, `개요 1`, `개요 2`를 찾는다(영문 Normal / Outline 1 / Outline 2도 인식). 없으면 본문 스타일을 쓰고 그 사실을 알린다.
- `Contents/section0.xml`의 **첫 문단은 남긴다**(용지·여백을 담은 `hp:secPr`가 들어 있음). 첫 문단의 예시 글자와 나머지 예시 본문은 지운다.
- 장 제목 문단에 `pageBreak="1"`을 넣어 장마다 새 쪽에서 시작한다.
- 다른 파일(header, 그림, 설정)은 바이트 그대로 둔다.

## 한계 — 사용자에게 꼭 알릴 것
- 결과는 **한글에서 직접 열어 확인**해야 한다(글자·문단·쪽 나눔). 이 스킬은 한글 프로그램으로 렌더링 검증을 하지 못한다.
- 각주·표·그림은 일반 문단으로 들어간다. 인용은 본문 괄호 `(저자, 연도)`로 둔다.
- 학교 서식이 개요 스타일 대신 다른 이름을 쓰면, 한글에서 해당 문단에 스타일을 다시 적용해야 할 수 있다.
