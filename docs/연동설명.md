# AI WIKI 사용 안내 (v9)

## 처음 시작하기 — 이전 자료 옮기기
1. 압축을 풀고 `AI-WIKI` 폴더를 **내 드라이브 → 한베MOU연구** 안에 넣습니다. (예전 AI-WIKI.html은 `AI-WIKI_예전.html`로 이름을 바꿔 보관)
2. **예전 AI WIKI를 쓰던 Chrome에서** 새 `AI-WIKI.html`을 엽니다(더블클릭 → Chrome). 예전 자료가 자동으로 **PRJ-001 한-베트남 MOU 동향 분석**으로 옮겨집니다. 원래 데이터는 지우지 않습니다.
3. 자료가 안 보이면: PRJ-001 → 연결 설정 → 볼트 폴더 연결(한베MOU연구) → 불러오는 범위 **볼트 전체** → **볼트에서 불러오기**. 옵시디언에 저장해 둔 논문 100편·MOU 115건·분석 노트가 다시 들어옵니다.

## KCI 검색·구글 드라이브 API를 쓰려면
- `AI-WIKI 시작.command`(Mac) / `AI-WIKI 시작.bat`(Windows)을 실행하면 `http://localhost:8765`로 열립니다.
- 주소가 바뀌면 브라우저 저장 공간이 따로라서, 처음 한 번 **예전 주소에서 전체 백업 → 새 주소에서 백업 복원**을 합니다.
- KCI 인증키, 구글 OAuth 클라이언트 ID, Claude API 키는 **연결 설정**에서 등록합니다.

## 화면 구성
- 대문: 7단계 사용 설명서, 저장 위치, 내 프로젝트, 신규 프로젝트
- 신규 프로젝트: ① 글 형태 ② 주제·키워드·나의 관점 ③ 옵시디언·구글 드라이브 폴더 동시 생성
- 프로젝트 메뉴: 대시보드 · 연구 설정 · 자료 수집 · 자료 관리·판단 · 토픽 분류·방향 · 참고문헌 · AI 집필 · 검토·수정 · 출력·서식 · 연결 설정
- 모든 프로젝트 화면 위 **KCI 논문 검색창** → 받으면 **즉시 AI 분석**(관련도·토픽·근거) → 채택·보류·제외
- 토픽 분류는 채택 문헌 기준(채택이 없으면 제외하지 않은 문헌)

## 기능 상태
- 키 없이 동작: 프로젝트·저장, 가져오기, 자동 관련도 분석(규칙 기반), 토픽 분류, 방향 후보, 집필, 참고문헌, DOCX·PDF·Markdown 출력
- Chrome에서 동작: 옵시디언 볼트 읽기·쓰기, 프로젝트 폴더 생성
- 키·계정 필요(실서비스 미검증): KCI(인증키+로컬 서버), Google Drive API(클라이언트 ID+로컬 서버), Claude(API 키)
- **HWPX(시험)**: 학교 HWPX 서식에 내용을 채움. 한글에서 열어 확인해야 정식 기능
- 미구현: 원문 PDF 내용 분석, 그림 이미지 삽입, 구역별 쪽 번호
