# Claude Code → 깃허브 자동 커밋 · 설치 도우미

## 1. 자동 커밋은 어떻게 동작하나
- 이 저장소의 `.claude/settings.json`에 Claude Code **Stop 훅**이 들어 있습니다. Claude Code가 한 번의 답변(작업)을 마칠 때마다 `.claude/hooks/auto-commit.sh`가 실행됩니다.
- 바뀐 파일이 있으면 `git add -A` → 커밋(시각·파일 목록이 담긴 메시지) → `origin`에 푸시합니다.
- 안전장치
  - 반복 실행 방지: `stop_hook_active`가 true면 아무것도 하지 않습니다.
  - 비밀값 차단: 바뀐 내용에 API 키·토큰처럼 보이는 값(sk-ant-…, ghp_…, AIza…, kci_key)이 있으면 커밋하지 않고 경고합니다.
  - `.gitignore`에 적힌 파일(키 설정, 연구 백업 데이터)은 올라가지 않습니다.
  - 강제 푸시(force push)는 하지 않습니다.
- 끄기: 저장소 루트에 `.no-auto-commit` 파일을 만들거나 환경변수 `AIWIKI_AUTO_COMMIT=0`. 커밋만 하고 올리지 않으려면 `AIWIKI_AUTO_PUSH=0`.
- Windows에서는 Git for Windows(Git Bash)가 있어야 훅 스크립트가 실행됩니다.

## 2. 설치 도우미 (git · Claude Code · AI WIKI 한 번에)
| 운영체제 | 실행 |
| --- | --- |
| Mac | `install/install-mac.command` 더블클릭 (미리 보기: `--dry-run`) |
| Windows | PowerShell에서 `powershell -ExecutionPolicy Bypass -File .\install\install-windows.ps1` (미리 보기: `-DryRun`) |

순서: ① git 확인·설치(Mac: Apple 개발자 도구, Windows: winget Git) ② Claude Code 공식 설치 명령 ③ GitHub CLI로 브라우저 로그인(가능할 때) ④ AI WIKI 저장소 clone(이미 있으면 pull) ⑤ 자동 커밋 준비 → AI WIKI 실행

처음 쓸 때 저장소 주소를 묻습니다. 미리 정하려면 환경변수 `AIWIKI_REPO`에 주소를 넣으세요.
