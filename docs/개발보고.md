# AI WIKI 최종 보고 (1~8단계)

프로젝트 기반 통합 연구 시스템. 자료 수집 → 자료 관리 → AI 분석 → 연구 설계 → 집필 → 문서 출력.

## 1. 실제로 동작하는 것과 조건부·미구현 구분

| 구분 | 기능 | 상태 |
| --- | --- | --- |
| **실제 동작** (키·계정 없이) | 프로젝트 생성·전환·백업, IndexedDB 저장, 엑셀·CSV·JSON 가져오기, 직접 입력, 중복 감지·병합, 키워드 사전, 규칙 기반 분류(관련도·토픽·문헌 유형), 통계 토픽 모델링(TF-IDF·k-평균), 문헌 비교·동향 신호·규칙 기반 연구 방향 후보, 연구 설계·주장/근거·장별 집필·검토, 참고문헌, DOCX·PDF·Markdown·HTML 출력, 출력 전 검증, 상태 센터 | 검증 완료 |
| **실제 동작** (Chrome·Edge) | Obsidian 볼트 폴더 읽기·쓰기(File System Access API), 원문 파일을 볼트 원문 폴더에 저장 | 연구자 PC에서 v1~v2로 실제 연결 확인, 이후 버전은 가상 폴더로 자동 시험 |
| **조건부** (키·계정 필요) | KCI 검색·상세·가져오기 | 로컬 연동 서버 + KCI 인증키 필요. 서버 코드는 실제로 실행해 시험, KCI 응답은 명세 기반 가짜 서버로 시험 — **실제 KCI 미검증** |
| **조건부** | Google Drive 로그인·폴더 생성·파일 목록·업로드·문헌 연결 | localhost + OAuth 클라이언트 ID 필요. 구글 응답은 가로채기로 시험 — **실제 계정 미검증** |
| **조건부** | Claude 분류·문헌 카드·토픽 해석·종합·설계 초안·장 집필 | API 키 필요. 응답 가로채기로 시험 — **실제 응답 품질 미검증** |
| **미구현** | HWPX 출력 | 한글로 열어 검증할 경로가 확인되지 않음. 대체: DOCX → 한글에서 HWPX로 저장 |
| **미구현** | 원문 PDF 내용 분석 | 원문은 보관·연결만, 분석은 제목·초록·키워드만 사용 |
| **미구현** | 그림 이미지 삽입, 구역별 쪽 번호, 볼트 자동 동기화 | 그림은 캡션 달린 자리 표시, 쪽 번호 단일 구역, 불러오기·저장은 버튼 |

## 2. 데이터 저장 구조

- **브라우저 IndexedDB `aiwiki-db`**
  - `data` 저장소: `global`(Claude 키·모델·Drive 클라이언트 ID·프로젝트 번호), `index`(프로젝트 목록 요약), `prj:<ID>`(프로젝트 전체), `tpl:<ID>`(서식 파일)
  - `h` 저장소: `vault:<ID>`(프로젝트별 볼트 폴더 권한 핸들)
- **프로젝트(`prj:<ID>`) 안**: settings(주제·문서 유형·키워드·목적·관점…), items(문헌·MOU·노트), files(원문 파일 참조: Drive 파일 ID·링크 또는 볼트 경로), keywords(키워드 사전), topics, cards(문헌 카드), analyses(분석 버전), viewHistory(관점 이력), design(연구 설계), designHistory, writing(장별 본문·버전·인용·검토), format·front(출력 서식·표지), exportLog, log(동기화·오류 기록)
- **로컬 연동 서버**: KCI 인증키만 `~/.aiwiki/config.json`(권한 600)에 저장. 앱·볼트·드라이브에는 저장하지 않음
- **주소별 저장 공간**: `file://`와 `http://localhost:8765`는 브라우저 저장 공간이 따로라, 옮길 때 전체 백업 → 복원 필요

## 3. Obsidian·Google Drive 연동 방식

- **Obsidian**: 브라우저가 허락한 볼트 폴더를 직접 읽고 씀. 새 프로젝트는 `1-Projects/PRJ-번호_이름/`(문헌·데이터·원문·분석·원고·연구노트)와 속성 `project_ids`에 프로젝트 ID가 있는 노트만 불러옴. "변경 사항 확인" 후 가져오기, 바뀐 노트만 다시 읽음. 앱이 만든 노트는 `generated_by: "AI WIKI"`로 원본과 구분하고 원본 노트는 고치지 않음
- **Google Drive (두 경로)**
  1. 동기화 폴더: 볼트를 Google Drive 데스크톱 앱의 "내 드라이브"에 두면, 볼트에 저장한 파일이 자동으로 클라우드에 올라감(앱은 실제 위치를 알 수 없어 연구자 확인 값으로 표시)
  2. Drive API: OAuth 2.0(Google Identity Services) + Drive API v3. 기본 권한 `drive.file`, 선택 시 `drive.readonly`. 프로젝트 폴더 `AI WIKI/PRJ-번호_이름` 생성, 파일 목록·업로드, 파일 ID·MIME·크기·링크·md5 기록. 토큰은 메모리에만

## 5. 테스트로 발견해 고친 오류

- 규칙 분류: 긴 키워드 구절 통째 비교로 토픽이 거의 안 붙음 → 단어 단위 + 흔한 단어 가중치 축소(IDF), 한 단어만 맞는 약한 단서는 토픽 미지정
- 토큰화: "fta의"·"경제효"(효과→효) 오류 → 영문·한글 분리, 조사처럼 끝나는 명사 보호
- 집필 검토: 끝에 인용이 붙은 문장을 잘못 나눠 근거 부족으로 오판 → 문장 나누기 수정
- 연구 설계 저장 시 관점이 분석에 반영되지 않음 → 저장 시 반영 + 관점 이력
- DOCX: 목차 갱신 설정 순서 오류, 서식 파일 스타일에 쉼표 섞임, 빈 쪽 생성, 서식 파일 적용 시 장 쪽 나눔 누락 → 모두 수정 후 스키마 통과
- 상태 표시: API 키 저장만으로 "Claude 연결", KCI 키 등록만으로 "KCI 연결됨"이 뜸 → 실제 요청 성공 기록이 있을 때만 정상으로 표시
- KCI 상세: 다른 논문의 상세 응답이 섞일 위험 → 논문 ID가 일치할 때만 합침
- 데이터: 연구자 엑셀 100편 중 P034와 P010이 같은 논문(실제 고유 99편), 4건(P055~P058)은 열이 한 칸씩 밀려 있었음(변환 시 보정)

## 7. 9단계 — 설계안 반영(처음 AI WIKI 틀 복귀)
- 대문: 7단계 사용 설명서 흐름도(자동/연구자 판단 색 구분), 저장 위치, 프로젝트 표
- 신규 프로젝트 3단계: 글 형태 → 주제·키워드·나의 관점(필수) → 옵시디언·구글 드라이브 폴더 동시 생성(연결 안 된 곳은 "만들지 않음"으로 표시)
- 메뉴 10개(처음 AI WIKI 순서), 대시보드(지표 4·관련도 등급·토픽·출처·내 연구·최근 자료)
- 상단 KCI 검색창, 받는 즉시 AI 분석(KCI·옵시디언·드라이브·업로드·목록 모두), 채택·보류·제외 판단
- 토픽 분류·방향: 채택 문헌 기준 토픽 수 지정 → 중심 토픽·방향 선택 → 나의 관점 → 목차 확정 후 집필
- 참고문헌: 처음 형태(관련도 필터·양식·목록 복사) + 인용 현황 보기
- 검토·수정: 모든 장의 검토 항목과 주장별 근거 상태를 한곳에
- HWPX(시험): 학교 HWPX 서식의 용지·스타일(바탕글·개요 1·개요 2)을 유지하고 본문을 채움. 시험용 서식으로 구조·XML 검증, 한글 실행 검증은 미완
- 테스트: 새 흐름 43/43, 3~7단계 회귀 178/178, DOCX 스키마 통과
- 테스트로 고친 것: 볼트 연결 기억 실패 시 폴더 생성까지 멈추던 문제, 규칙 기반 방향 후보가 3개 미만이던 문제(관점 검증 방향 추가), 장 뼈대에 근거 문헌 후보가 없던 문제, 참고문헌 처음 화면에 서식 미확인 안내가 빠졌던 문제

## 8. 10단계 — 승인된 시안과 화면 일치
- 대문·신규 프로젝트: 왼쪽 메뉴 없이 전체 폭, 위쪽 가로 막대(로고 · 신규 프로젝트)
- 왼쪽 메뉴: 로고 → 프로젝트 번호·글 형태 → 프로젝트 이름 → 메뉴 10개 → 연결 상태(Obsidian · Google Drive · KCI · AI)
- 상단: KCI 논문 검색 입력창 + 안내 한 줄
- 자료 수집: 알약 탭, 큰 검색창, "더 자세히"(저자·학술지·기간·키워드), 검색 결과(왼쪽) | 받은 즉시 AI 분석(오른쪽)
- 테스트로 고친 것: 검색 진행 표시 자리가 없어 검색이 멈추던 문제, 연결 안 됐는데 검색 버튼이 눌리던 문제(잠금+이유 표시), 휴대폰에서 메뉴가 항상 펼쳐져 본문을 가리던 문제, 휴대폰에서 상단 검색창이 아래 내용을 가리던 문제, 휴대폰에서 프로젝트 "열기" 버튼이 숨겨지던 문제
